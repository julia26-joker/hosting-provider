# Хостинг-провайдер

Веб-сервис для аренды виртуальных машин и контейнеров с SSH-доступом. Лабораторная работа №3, 3-й модуль ACOS.

## Описание

Проект реализует упрощённый хостинг-провайдер: пользователь через веб-интерфейс настраивает и запускает виртуальную машину или контейнер, после чего получает SSH-доступ к арендованной машине. Фоновый монитор автоматически останавливает инстансы по истечении времени аренды.

**Возможности:**
- Создание контейнеров (Docker) и виртуальных машин (QEMU)
- Выбор типа, ОС и ресурсов (CPU, RAM, диск)
- SSH-доступ к каждому инстансу
- Просмотр списка инстансов и их статуса в реальном времени
- Ручная остановка инстансов через UI
- Автоматическое гашение инстансов по таймеру

## Архитектура

```
hosting-provider/
├── backend/
│   ├── api.py            # REST API (FastAPI)
│   ├── docker_manager.py # Управление контейнерами через Docker
│   ├── qemu_manager.py   # Управление VM через QEMU
│   └── models.py         # Pydantic-модели
├── database/
│   └── db.py             # SQLite база данных
├── frontend/
│   └── app.py            # Веб-интерфейс (Streamlit)
├── monitor/
│   └── monitor.py        # Фоновый мониторинг инстансов
└── requirements.txt
```

## Стек технологий

- **Frontend**: Streamlit
- **Backend**: FastAPI + Uvicorn
- **Виртуализация**: QEMU (VM), Docker (контейнеры)
- **База данных**: SQLite
- **Язык**: Python 3.12
